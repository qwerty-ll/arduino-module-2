# Arduino для школьников. Модуль 2: виртуальная лаборатория

Занятия 9–16 программы дополнительного образования по Arduino. Весь модуль проходит в онлайн-симуляторе [Cirkit Designer](https://www.cirkitdesigner.com): 8 занятий по 90 минут, в конце — хакатон.

Продолжение модуля 1 (занятия 1–8: Blink, SOS, кнопки и звук, циклы и массивы, ШИМ, датчик звука, RFID).

## Карта пинов модуля

У каждой детали постоянный пин, поэтому финальные проекты собираются без конфликтов.

| Деталь | Пины Arduino Uno |
| --- | --- |
| Кнопка | D2 + GND (`INPUT_PULLUP`) |
| RGB-светодиод | D3, D5, D6 |
| DHT22 | D4 |
| HC-SR04 | TRIG D7, ECHO D12 |
| Баззер | D8 |
| Сервопривод | D9 |
| LCD 16×2 I2C | SDA A4, SCL A5 |
| Потенциометр | A0 |
| Клавиатура 4×4 | ряды D13–D10, колонки D7–D4 (только «Сейф 2.0») |

## Библиотеки

LiquidCrystal I2C (Marco Schwartz), DHT sensor library (Adafruit), Keypad, Servo (встроенная). В Cirkit Designer подключаются через Code → Libraries → Include.
